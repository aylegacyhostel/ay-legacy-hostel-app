# AY Legacy Hostel Management System

Multi-user Flask hostel management application prepared for online hosting with PostgreSQL/Supabase support.

## Main features
- Secure staff login with roles
- Student records, rooms, payments, arrears and enquiries
- Partial-payment tracking
- Audit log for important changes
- PostgreSQL support for shared simultaneous access
- Migration utility for existing SQLite records
- Render deployment configuration
- AY Legacy Hostel building image used as the backdrop across the app
- Dynamic Program filter on the student list

## Deployment
See the deployment steps in this repository and configure `DATABASE_URL` and `SECRET_KEY` as environment variables on the hosting service.
